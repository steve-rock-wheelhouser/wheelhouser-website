# Text Editor v0.14.2

We are excited to announce the release of **Text Editor v0.14.2**. This update brings our modern desktop text editor to version 0.14.2 under the GNU General Public License v3.0 (GPL-3.0), featuring standardized multi-distribution Linux packaging (RPM & DEB) for Enterprise Linux (Rocky Linux 10, AlmaLinux 10), Fedora 44, Debian 13, and Ubuntu 24 via `repo.wheelhouser.com`, alongside Windows 10/11 and macOS.

## 🚀 Key Features

*   **Multi-Language Syntax Highlighting:** High-performance color coding for Python, C, C++, Java, Rust, Ruby, JavaScript, TypeScript, HTML, CSS, Markdown, JSON, and Shell scripts.
*   **Code Folding & Structure Navigation:** Fold and unfold logical blocks with intuitive keyboard shortcuts and persistent folding states.
*   **Simultaneous Multi-Cursor Editing:** Place multiple carets for blazing-fast parallel editing and batch modifications.
*   **Wheelhouser Dark Theme:** Ergonomic native dark aesthetic engineered for long coding and writing sessions.
*   **Native Multi-Distro Delivery (RPM & DEB):** Standardized packages built with Python 3.13 for Rocky Linux 10, AlmaLinux 10, Fedora 44, Debian 13, and Ubuntu 24 via `repo.wheelhouser.com`.
*   **Integrated Spell Checking:** On-the-fly spelling suggestions with custom user dictionary management.
*   **True Cross-Platform Parity:** Consistent UI, keystrokes, and feature set across Linux, Windows, and macOS.

## 🛠 Technical Details

*   **Version:** 0.14.2
*   **Runtime / Framework:** Python 3.13 / PySide6 / Qt6
*   **License:** GNU General Public License v3.0 (GPL-3.0)
*   **Target Distros:** Rocky Linux 10, AlmaLinux 10, Fedora 44, Debian 13, Ubuntu 24
*   **Cross-Platform:** Linux (RPM & DEB), Windows (Microsoft Store), macOS

## 📦 Downloads & Installation

*   **Rocky Linux 10 / AlmaLinux 10 / Fedora 44:** Available via `sudo dnf install text-editor` from `repo.wheelhouser.com`.
*   **Debian 13 / Ubuntu 24:** Available via `sudo apt install text-editor` from `repo.wheelhouser.com`.
*   **Windows:** Available on the Microsoft Store.
*   **macOS:** GitHub Releases.
