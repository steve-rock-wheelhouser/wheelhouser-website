About the Application

Text Editor is an ergonomic, high-performance desktop code and plain text editor developed by Wheelhouser LLC. Designed for developers, systems engineers, and writers, it combines lightning-fast file operations with advanced code editing capabilities in a cohesive, distraction-free environment.

Featuring multi-cursor editing, multi-level code folding, intelligent auto-indentation, find and replace with regex support, dynamic tab favicons, and integrated spell checking, Wheelhouser Text Editor is optimized for both everyday notes and demanding source code development across Linux, Windows, and macOS.

Key Features

  • Multi-Language Syntax Highlighting: First-class color coding for Python, C, C++, Java, Rust, Ruby, HTML, CSS, JavaScript, TypeScript, Markdown, JSON, Shell scripts, and PowerShell.
  • Code Folding & Structure Navigation: Collapse and expand code blocks with keyboard shortcuts (Ctrl+Shift+[ / Ctrl+Shift+]), preserving folding states across application restarts.
  • Simultaneous Multi-Cursor Editing: Multiple cursors (Ctrl+Click, Ctrl+D, Ctrl+Alt+Up/Down) for blazing fast parallel refactoring and editing.
  • Wheelhouser Dark & Theme Customization: Native dark mode with user-definable ANSI color palettes, typography customization, and dynamic JSON theme plugins.
  • Integrated Spell & Grammar Check: Real-time spelling suggestions and custom dictionary management powered by pyspellchecker.
  • Native RPM Packaging: Built and signed for Enterprise Linux (Rocky Linux 10) and Fedora with full desktop icon integration and DNF repository delivery.
