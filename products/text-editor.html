About the Application

Text Editor is an ergonomic, high-performance desktop code and plain text editor developed by Wheelhouser LLC. Designed for developers, systems engineers, and writers, it combines lightning-fast file operations with advanced code editing capabilities in a cohesive, distraction-free environment with true cross-platform parity.

While there are countless notepad utilities available, very few deliver genuine, first-class cross-platform support across modern enterprise and community Linux distributions, Windows, and macOS. Featuring multi-cursor editing, multi-level code folding, intelligent auto-indentation, find and replace with regex support, dynamic tab favicons, and integrated spell checking, Wheelhouser Text Editor is optimized for everyday notes and demanding source code development alike on Rocky Linux 10, AlmaLinux 10, Fedora 44, Debian 13, Ubuntu 24, Windows 10/11, and macOS.

Key Features

  • True Cross-Platform Parity: Identical ergonomic editing workflow, keyboard shortcuts, and theme consistency across Linux (RPM & DEB), Windows 10/11, and macOS.
  • Multi-Language Syntax Highlighting: First-class color coding for Python, C, C++, Java, Rust, Ruby, HTML, CSS, JavaScript, TypeScript, Markdown, JSON, Shell scripts, and PowerShell.
  • Code Folding & Structure Navigation: Collapse and expand code blocks with keyboard shortcuts (Ctrl+Shift+[ / Ctrl+Shift+]), preserving folding states across application restarts.
  • Simultaneous Multi-Cursor Editing: Multiple cursors (Ctrl+Click, Ctrl+D, Ctrl+Alt+Up/Down) for blazing fast parallel refactoring and editing.
  • Wheelhouser Dark & Theme Customization: Native dark mode with user-definable ANSI color palettes, typography customization, and dynamic JSON theme plugins.
  • Integrated Spell & Grammar Check: Real-time spelling suggestions and custom dictionary management powered by pyspellchecker.
  • Native Linux Packaging (RPM & DEB): Built with Python 3.13 and cryptographically signed for Enterprise Linux (Rocky Linux 10, AlmaLinux 10), Fedora 44, Debian 13, and Ubuntu 24 with desktop menu integration and repository delivery.

Debian 13 (Trixie)

Install GPG keyring and repository source:

sudo install -m 0755 -d /etc/apt/keyrings && curl -fsSL https://repo.wheelhouser.com/steve-rock-wheelhouser-gpg.key | sudo gpg --dearmor -o /etc/apt/keyrings/wheelhouser.gpg && sudo chmod a+r /etc/apt/keyrings/wheelhouser.gpg
echo "deb [signed-by=/etc/apt/keyrings/wheelhouser.gpg] https://repo.wheelhouser.com/debian/13 ./" | sudo tee /etc/apt/sources.list.d/wheelhouser.list
sudo apt update && sudo apt install -y text-editor
