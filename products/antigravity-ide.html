Google Antigravity IDE

Official Linux RPM & DEB packaging, desktop integration, and launcher utility for Google Antigravity IDE.

v1.0.0-38 GPL-3.0 Rocky Linux 10 • AlmaLinux 10 • Fedora 44 • Debian 13 • Ubuntu 24

About the Application

Google Antigravity IDE is the next-generation agentic AI development environment developed by Google DeepMind. While Google officially provides native installers for Windows and macOS, enterprise and community Linux distributions require dedicated system packaging and desktop environment integration. Wheelhouser LLC provides complete open-source RPM and Debian packaging, automated deployment tooling, and native Linux desktop integration for Rocky Linux 10, AlmaLinux 10, Fedora 44, Debian 13 (Trixie), and Ubuntu 24 (Noble).

This package coordinates system launcher wrappers, registers the GNOME/XDG application menu launchers with high-resolution icons, configures desktop mime-type associations, downloads the stable Antigravity IDE runtime payload directly from official Google channels, and manages single-instance session locking and daemon cleanup.

Key Features

  • Native RPM & DEB Packaging: Built and cryptographically signed following modern Fedora/EL10 (RPM) and Debian/Ubuntu (DEB) packaging guidelines.
  • Complete Cross-Platform Ecosystem: Complements Google's official Windows and macOS native releases by delivering first-class enterprise packaging for Linux workstations and servers.
  • Full Desktop Integration: Installs high-resolution vector and raster icons, XDG menu launchers (antigravity-ide.desktop), and terminal aliases.
  • Multi-Distro Enterprise Parity: Fully verified installation, execution, and update lifecycles across Rocky Linux 10, AlmaLinux 10, Fedora 44, Debian 13, and Ubuntu 24.
  • Smart Process & Instance Management: The launcher utility enforces single-instance session locking and automatically cleans up orphaned background agent daemons.
  • Cryptographic Distribution: Hosted and signed with Wheelhouser LLC's 4096-bit RSA release key via our custom RPM and APT repository endpoints.
  • CLI & GUI Dual Access: Launch effortlessly from your desktop application grid or directly from the terminal via antigravity-ide or antigravity.

Rocky Linux 10 / Enterprise Linux

Install repository release package and application:

sudo dnf install https://repo.wheelhouser.com/rocky/10/x86_64/steve-rock-wheelhouser-release-1.0-6.el10.noarch.rpm
sudo dnf install antigravity-ide

AlmaLinux 10

Install repository release package and application:

sudo dnf install https://repo.wheelhouser.com/almalinux/10/x86_64/steve-rock-wheelhouser-release-1.0-6.el10.noarch.rpm
sudo dnf install antigravity-ide

Fedora Linux 44

Install repository release package and application:

sudo dnf install https://repo.wheelhouser.com/fedora/44/x86_64/steve-rock-wheelhouser-release-1.0-6.fc44.noarch.rpm
sudo dnf install antigravity-ide

Debian 13 & Ubuntu 24 (APT)

Install GPG keyring and repository source:

sudo install -m 0755 -d /etc/apt/keyrings && curl -fsSL https://repo.wheelhouser.com/steve-rock-wheelhouser-gpg.key | sudo gpg --dearmor -o /etc/apt/keyrings/wheelhouser.gpg && sudo chmod a+r /etc/apt/keyrings/wheelhouser.gpg

# For Debian 13:
echo "deb [signed-by=/etc/apt/keyrings/wheelhouser.gpg] https://repo.wheelhouser.com/debian/13 ./" | sudo tee /etc/apt/sources.list.d/wheelhouser.list

# For Ubuntu 24:
# echo "deb [signed-by=/etc/apt/keyrings/wheelhouser.gpg] https://repo.wheelhouser.com/ubuntu/24 ./" | sudo tee /etc/apt/sources.list.d/wheelhouser.list

sudo apt update && sudo apt install antigravity-ide
