Rocky Linux Setup

Automated workstation provisioning, repository bootstrapping, and developer environment management CLI for Enterprise Linux 10.

v1.0.0-1 GPL-3.0 Rocky Linux 10

About the Application

Rocky Linux Setup is an automated workstation provisioning and developer orchestration suite engineered by Wheelhouser LLC for Rocky Linux 10 and Enterprise Linux systems. Designed to eliminate manual setup overhead across physical developer workstations, virtual machines, and cloud instances, it bootstraps official Wheelhouser repositories, configures essential upstream package channels, and provisions modern development environments.

Packaged natively as an RPM meta-package (rocky-linux-setup), it coordinates repository activation (including CodeReady Linux Builder and EPEL 10), installs development and RPM packaging toolchains, integrates Google Antigravity IDE, and supplies the rocky-linux-setup management CLI for ongoing system health auditing.

Key Features

  • Repository Coordination: Installs the official Wheelhouser release package and automatically enables CodeReady Linux Builder (CRB) and EPEL 10.
  • Developer Toolchain Provisioning: Deploys core engineering utilities (git, curl, wget) alongside native RPM packaging suites (rpm-build, rpm-sign, createrepo_c).
  • Workstation Desktop Integration: Automatically provisions and configures Google Antigravity IDE with desktop launcher menus, icons, and shell shortcuts.
  • Interactive Management CLI: Includes /usr/bin/rocky-linux-setup to audit workstation readiness, inspect repository states, adjust hostnames, and manage GPG release keys.
  • 100% Unattended OS Automation: Ships production-tested Kickstart profiles (rocky10-workstation.ks) for hands-free bare-metal and KVM/QEMU automated installations.
  • Enterprise Cryptographic Signing: Hosted and cryptographically signed with Wheelhouser LLC's 4096-bit RSA key on repo.wheelhouser.com.

Management CLI Commands

The installed rocky-linux-setup CLI provides quick administrative diagnostics and configuration helpers:

# Inspect system health, repository status, and build toolchains:
rocky-linux-setup --status

# Enable CodeReady Linux Builder (CRB) and EPEL 10:
sudo rocky-linux-setup --enable-crb

# Configure system hostname:
sudo rocky-linux-setup --set-hostname rocky10-workstation

# Import custom RPM signing key and set ultimate trust:
rocky-linux-setup --import-key ~/wheelhouser-release-private.asc

Downloads & Installation

Quick Install via DNF

Configure Wheelhouser repo and install meta-package:

sudo dnf install https://repo.wheelhouser.com/rocky/10/x86_64/steve-rock-wheelhouser-release-1.0-6.el10.noarch.rpm
sudo dnf install -y rocky-linux-setup
rocky-linux-setup --status

Unattended OS Kickstart

Boot parameter for ISO or PXE installer:

inst.ks=https://raw.githubusercontent.com/steve-rock-wheelhouser/rocky-linux-setup/main/kickstart/rocky10-workstation.ks
